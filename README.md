# CodeAlpha-Python-Tasks
Python tasks submitted for the CodeAlpha virtual internship.

This repository contains the tasks completed as part of the virtual Python programming internship at CodeAlpha. The projects focus on fundamental programming concepts including control flow, data structures, and file handling.

## 📂 Project Structure

### Task 1: Hangman Game (`task1_hangman.py`)
A terminal-based word guessing game. 
* **Features:** Selects a random word from a predefined list, tracks guessed letters, and limits the user to 6 incorrect attempts.
* **Key Concepts:** `random` module, `while` loops, strings, and lists.

### Task 2: Stock Portfolio Tracker (`task2_portfolio_tracker.py`)
A financial tracking script that calculates the total value of a stock portfolio based on manual user inputs.
* **Features:** Maps user-inputted quantities to a hardcoded dictionary of stock prices, calculates total investment, and exports a formatted summary to a `.txt` file.
* **Key Concepts:** Dictionaries, `try-except` error handling, basic arithmetic, and file I/O operations.

### Task 4: Basic Chatbot (`task4_chatbot.py`)
A simple, rule-based conversational agent.
* **Features:** Takes user string input, standardizes it, and returns predefined responses based on specific keyword triggers (e.g., greetings and farewells).
* **Key Concepts:** `if-elif-else` control flow, continuous `while` loops, and string manipulation (`.lower()`, `.strip()`).

To run any of these scripts locally on your machine, you must have Python installed. 

1. Clone or download this repository to your local machine.
2. Open your terminal or command prompt.
3. Navigate to the folder containing the downloaded scripts.
4. Run the desired script using the `python` command followed by the filename:
